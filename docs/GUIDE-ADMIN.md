## Ελληνικά

### Σύνδεση
1. Ανοίξτε **https://dimogdor.github.io/Evergreen/admin/** (ή τον σύνδεσμο «Admin» στο κάτω μέρος κάθε σελίδας).
2. Πατήστε **Sign in with GitHub**. Χρειάζεστε δωρεάν λογαριασμό GitHub που έχει προστεθεί ως συνεργάτης στο αποθετήριο.
3. Ελληνικά μενού: εικονίδιο λογαριασμού (πάνω δεξιά) → **Settings** → **Appearance** → γλώσσα **Ελληνικά**.

> Κάθε **Save** ενημερώνει το site μέσα σε **περίπου 2 λεπτά**. Τίποτα δεν χάνεται: κάθε αλλαγή μένει στο ιστορικό και μπορεί να αναιρεθεί.

### Τι μπορείτε να αλλάξετε (όλα χωρίς κώδικα)
| Μενού | Τι αλλάζει |
|---|---|
| **Ημερολόγιο** | Εκδηλώσεις: ημερομηνίες, **ώρα** (ώρα Ελλάδας — οι επισκέπτες τη βλέπουν στη δική τους ζώνη ώρας όταν την προσθέτουν στο ημερολόγιό τους), τιμή, τοποθεσία, φωτογραφία, σύνδεσμος κράτησης. |
| **Δραστηριότητες** | Κάθε δραστηριότητα και η σελίδα της (κείμενο, τιμές, ερωτήσεις, φωτογραφίες). «Στην αρχική» = εμφανίζεται στην πρώτη σελίδα. |
| **Κάτοικοι** | Άνθρωποι, ζώα, φυτά: όνομα, ρόλος, λίγα λόγια, φωτογραφία. Χωρίς φωτογραφία εμφανίζονται τα αρχικά. |
| **Γκαλερί** | Άλμπουμ φωτογραφιών και βίντεο. |
| **Ιστορίες** | Μαρτυρίες πρώην εθελοντών/επισκεπτών — έγκριση πριν τη δημοσίευση (βλ. παρακάτω). |
| **Σελίδες** | Όλα τα κείμενα και οι φωτογραφίες κάθε σελίδας. Στην **Αρχική** μπορείτε και να κρύψετε ενότητες. |
| **Νέες σελίδες** | Φτιάξτε δικές σας σελίδες (π.χ. ένα φεστιβάλ)· «Στο μενού» = εμφανίζεται στο μενού. Εδώ είναι και η σελίδα Απορρήτου. |
| **Ρυθμίσεις → Στοιχεία** | Email, τηλέφωνα, social, διεύθυνση, **IBAN/τράπεζα**, άλλες επαφές (στούντιο, ρητρίτ), μπάρα ανακοίνωσης, **χρώματα** του site, φωτογραφία κοινοποίησης. |
| **Ρυθμίσεις → Μικρά κείμενα** | Κάθε μικρό κείμενο: μενού, κουμπιά, ετικέτες, μηνύματα φόρμας — σε 8 γλώσσες. |

### Εκδήλωση στο ημερολόγιο
**Ημερολόγιο → New** → τίτλος, ημερομηνία έναρξης (και λήξης αν κρατά πάνω από μία μέρα), ώρα αν υπάρχει (π.χ. `18:00`), κατηγορία, περιγραφή, τιμή, φωτογραφία → **Save**. Οι παλιές εκδηλώσεις φεύγουν αυτόματα από το site. **Κρυφό** = κρύβεται χωρίς να σβηστεί. Κάθε εκδήλωση έχει αυτόματα κουμπί «Προσθήκη στο ημερολόγιο» (Google / Apple / Outlook).

### Ιστορίες (μαρτυρίες) — έγκριση
1. Ένας επισκέπτης στέλνει την ιστορία του από τη σελίδα **Ιστορίες**.
2. Λαμβάνετε **email από το GitHub** («New story from … — waiting for your approval») με σύνδεσμο.
3. Στο admin: **Ιστορίες** → φίλτρο **⏳ Waiting for approval** → ανοίξτε την ιστορία, διορθώστε αν χρειάζεται, τικάρετε **Published** → **Save**. Για απόρριψη: **Delete**.
4. Μπορείτε και να προσθέσετε μόνοι σας ιστορίες με φωτογραφία (**New**).

> Για να έρχονται τα email: στο github.com/Dimogdor/Evergreen πατήστε **Watch → All Activity** (μία φορά).

### Φωτογραφίες & βίντεο
- Σύρετε πολλές φωτογραφίες μαζί· **συμπιέζονται αυτόματα** — ανεβάστε τες κατευθείαν από το κινητό. Η πρώτη φωτογραφία εμφανίζεται πρώτη· σύρετε για αλλαγή σειράς.
- Βίντεο: καλύτερα στο YouTube («Μη καταχωρισμένο») και επικόλληση συνδέσμου. Μικρά κλιπ (< 40 MB) ανεβαίνουν και ως αρχείο και συμπιέζονται αυτόματα.

### Μεταφράσεις (8 γλώσσες)
Αριστερά γράφετε στα **ελληνικά**, δεξιά βλέπετε άλλη γλώσσα. Αν μια γλώσσα μείνει κενή, το site δείχνει το αγγλικό (ή το ελληνικό) κείμενο. Το κουμπί **文A** μεταφράζει αυτόματα, αφού βάλετε **μία φορά** ένα κλειδί υπηρεσίας μετάφρασης: λογαριασμός → **Settings → Internationalization** (π.χ. Google Gemini, δωρεάν κλειδί από aistudio.google.com).

### Κάτι πήγε στραβά;
- Το site δεν άλλαξε; Περιμένετε 2 λεπτά και ανανεώστε (Ctrl+F5 / τραβήξτε προς τα κάτω στο κινητό).
- Επαναφορά: μέσα στην καταχώριση, εικονίδιο **ιστορικού** (ρολόι) δεξιά.

## English

### Signing in
1. Open **https://dimogdor.github.io/Evergreen/admin/** (or the “Admin” link at the bottom of every page).
2. Click **Sign in with GitHub**. You need a free GitHub account added as a collaborator on the repository.

> Every **Save** updates the website in **about 2 minutes**. Nothing is ever lost: every change stays in the history and can be undone.

### What you can change (all without code)
- **Calendar** — events with dates, **time** (Greek time; visitors get it converted to their own time zone when they add it to their calendar), price, place, photo, booking link.
- **Activities** — each activity and its page (text, prices, FAQ, photos). “Show on home page” puts it on the front page.
- **Inhabitants** — people, animals, plants (initials are shown when there is no photo).
- **Gallery** — photo and video albums.
- **Stories** — testimonials, approved before they go online (below).
- **Pages** — every text and photo of every page; on **Home** you can also hide whole blocks.
- **New pages** — create your own pages and put them in the menu. The privacy page lives here.
- **Settings → Site, contact & bank** — email, phones, social links, address, **IBAN/bank**, other contacts, top banner, **colours**, share photo.
- **Settings → Interface texts** — every small text (menu, buttons, labels, form messages) in 8 languages.

### Stories — moderation
A visitor sends a story → you get a **GitHub email** with a link → **Stories → ⏳ Waiting for approval** → open it, edit if needed, tick **Published**, **Save** (or **Delete** to refuse). You can add stories and photos yourself with **New**. To receive the emails, click **Watch → All Activity** once on github.com/Dimogdor/Evergreen.

### Translations
Greek on the left, any other language on the right; empty languages fall back to English, then Greek. The **文A** button translates automatically once a translation key is set (account → **Settings → Internationalization**, e.g. a free Google Gemini key).

### Something went wrong?
Wait 2 minutes and refresh. To restore an older version, open the entry and use the **history** (clock) icon.

## For the developer

- **Give someone access:** github.com/Dimogdor/Evergreen → Settings → Collaborators → *Add people* (role *Write*).
- **“Sign in with GitHub” and the Stories form** need the free Cloudflare Worker: follow [worker/README.md](../worker/README.md), then set `base_url` in `public/admin/config.yml` and **Settings → Website API address** in the admin. Until then, admins can sign in with **Sign in using access token** (a fine-grained GitHub token, Contents read/write on this repository only), and the Stories page shows an email button instead of the form.
- **Contact form:** paste a free key from web3forms.com in **Settings → Contact form key**; empty = email button only.
- **Updating the admin:** `public/admin/index.html` pins Sveltia CMS with an integrity hash. To update: pick a version on npmjs.com/package/@sveltia/cms, then
  `curl -sL https://unpkg.com/@sveltia/cms@VERSION/dist/sveltia-cms.js | openssl dgst -sha384 -binary | openssl base64 -A`
  and put the version and `sha384-…` hash in the script tag.
- **Custom domain:** see README → “Own domain”.
